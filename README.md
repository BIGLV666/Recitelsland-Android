# 背诵岛

背诵岛是一款用于题库练习、作答记录和间隔复习的 Android 应用。

## 功能

- 题库浏览、搜索和标签筛选
- 选择题、判断题、阅读理解
- 作答记录与答案解析
- 今日复习和复习计划
- 题目收藏
- 登录、个人资料和头像
- 浅色 / 深色模式
- 意见反馈

## 下载安装

在 GitHub Releases 下载最新 APK：

https://github.com/BIGLV666/Recitelsland-Android/releases/latest

- 支持 Android 8.0 及以上
- 如果手机安装过调试版，需要先卸载再安装正式版
